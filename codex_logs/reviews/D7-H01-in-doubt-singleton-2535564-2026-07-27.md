## 1. Decision and bounded claim

This candidate closes the first D7-H01 implementation slice. It makes the
existing checkpoint cardinality of at most one unresolved external effect
normative and implements that decision in both native runtimes.

The candidate establishes these exact rules:

1. `inDoubtActivities` is a singleton unresolved-external-effect projection,
   keyed by the stable activity key rather than by attempt.
2. A side-effect-free activity cannot enter that projection.
3. An ambiguous external failure inserts the claimed activity.
4. A later ambiguous attempt using the same stable activity key replaces the
   singleton only when its attempt is equal or higher.
5. A successful semantic outcome committed for that activity key clears the
   singleton.
6. A second unresolved external activity key is invalid history.
7. A fork inherits open or settled external uncertainty, including idempotent
   uncertainty, but cannot dispatch because its new controller run ID cannot
   reproduce the parent's activity key.
8. Fork blocking occurs after the child creation event binds lineage and before
   child lease acquisition or external handler dispatch.
9. Active resume may retry an idempotent activity with the same key; automatic
   retry of an unresolved non-idempotent activity remains prohibited.
10. Terminal cancellation retains only external claims, never a claim whose
    binding declares `sideEffects: none`.

This is not a claim that all of D7-H01 is complete. An authority-bound operator
resolution command/event, wrong-key and stale-fence rejection, duplicate
resolution idempotency, post-resolution checkpoint behavior, and settled
in-doubt resume/fork conformance remain open.
