## Runtime capability truth and public compatibility

After a full append-only plan scan, work moved to the highest-risk cross-cutting
runtime gap: compiler-valid Graph IR vocabulary could reach ordinary and durable
schedulers without its specialized semantics. Parallel lanes covered the
shared contract, TypeScript runtime, Python runtime and hostile public-surface
audit. No lane committed independently.

The accepted `runtime-capability/v1alpha1` preflight now runs in TypeScript and
Python ordinary execution, durable start and durable resume. Unsupported graphs
return `UNSUPPORTED_RUNTIME_CAPABILITY`, no node results, zero attempts and no
output. Ordinary execution does not inspect graph input first. Durable start and
resume perform zero event-store reads/appends. When registered foreign edge
conditions also occur, all runtime capability failures appear first and the
existing `UNSUPPORTED_EDGE_CONDITION` failures follow.

The executable alpha set is explicit: agent/model/tool/transform/router;
barrier only as `{}` or `{"condition":"all"}`; absent/value edges; false or
absent jitter; concurrency/depth/fan-out/attempt policies; and the compile-only
typed-port extension. Graph/node/edge schemas are accepted as compiler
contracts without claiming runtime value validation.

Rejected declarations cover graph state; subgraph/validator/human; other
barrier config; cache/resource/isolation; true jitter; edge map, stream and
artifact-ref; dynamic nodes, deadline and cost; and unknown policy extensions.
The shared seven-case corpus freezes 22 exact failures, including stable Unicode
code-point order for empty, `__proto__`, slash/tilde, `constructor`, accented
and emoji policy keys with exact RFC 6901 paths.

Audit findings materially changed the implementation. The first boundary was
too broad and would have rejected public schemas and every barrier, so it was
narrowed to compile-only schemas plus the existing static all-success join.
Review then found and closed runtime/condition ordering drift, TypeScript input
snapshot precedence, compiler-invalid corpus depth, quickstart
`maxDynamicNodes:0`, Python/CLI template and canonical-hash drift, generic
validator execution in the pattern showcase, stale routing/security claims, a
fresh-clone CLI build omission and a fixture validator that checked shape but
not graph semantics.

The semantic validator now checks unique IDs, endpoints, entrypoint rules,
reachability, cycles, depth and fan-out, with a direct hostile depth test. The
canonical quickstart, CLI template and Python bundled copy are byte-identical at
hash `f9aaeffc991e6cec223c959dbf7737a8fff96e1eb1ea433343f45fe663697b50`.
