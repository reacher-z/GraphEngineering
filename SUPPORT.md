# Support

Graph Engineering is an early alpha (`0.1.0-alpha.1`). Public APIs can change, but bug reports and
reproducible feedback are welcome.

- Use [GitHub Discussions](https://github.com/reacher-z/GraphEngineering/discussions)
  for design questions, usage help, and pattern ideas.
- Use [GitHub Issues](https://github.com/reacher-z/GraphEngineering/issues) for a
  minimal reproducible bug or an accepted feature proposal.
- Follow [SECURITY.md](SECURITY.md) for vulnerabilities; never disclose a
  suspected security issue in a public discussion or issue.

Include the exact version or commit, operating system, Node/Python version,
sanitized Graph IR, command, expected behavior, and actual structured failure.
Do not include API keys, private prompts, credentials, or production traces.
